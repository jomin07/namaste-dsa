Disjoint Set (Find and Union)
Set1: B ─── A ─── C          Set2: D ─── E          Set3: F ─── G ─── H
Set1: {A, B, C}
Set2: {D, E}
Set3: {F, G, H}
Operations

1. Find: Finds the representative (root/parent) of the set to which an element belongs.

Find(B): Set1
Find(D): Set2
Find(H): Set3

2. Union: Merges two different sets into one.

Example: create an edge between [B, D]. B ∈ Set1 and D ∈ Set2, so:

 Set1 {A,B,C}     Set2 {D,E}
      B ─ A ─ C       D ─ E
          \           /
           └── B─D ──┘
         merged into one set
   {A, B, C, D, E}  (one root/leader)
Set1 and Set2 are merged.
All elements of both sets now belong to one common set.
This set is represented by one root (leader).

Note: If both values belong to the same set, a union is not needed. Find and Union together are very helpful in detecting cycles in a graph.

Example Graph
      (1)───2───┐            ┌───3───(3)
       │         \          /        │
       1          (2)──────┤         4
       │         /  \      \         │
      (0)───5───┘    \      └──6───(4)
                      \              │
                       └─────7───────8
                                     │
                                    (5)

Edge list (weight): (0,1)=1, (1,2)=2, (2,3)=3, (3,4)=4, (0,2)=5, (2,4)=6, (2,5)=7, (4,5)=8

Exploring Edges

Arrows (↑) point from child to parent.

(0, 1): 1 joins 0.

  ↑
  1

  0

 1   2

(2, 3): 3 joins 0.

    0
  ↑ ↑ ↑

      0
  ↑ ↑ ↑ ↑
  4 1 2 3

(0, 2): If both u and v are in the same set, the edge forms a cycle.

(2, 4): Both are in the same set, so it forms a cycle.

(2, 5): 5 joins 0.

        0
  ↑  ↑  ↑  ↑
  4  1  2  3  5

All of 0, 1, 2, 3, 4 and 5 are now in one set with root 0.

Rank

Rank is an optimization used during the union operation to maintain a balanced tree, which helps the find operation run faster.

Solve with Array

The notes use two arrays: parent (the Uf root array) and rank. The index row is on top, the value row below.

(0, 1): 1’s parent becomes 0, and rank[0] becomes 1.

index  :  0  1  2  3  4  5
parent :  0  0  2  3  4  5
                ↑ changed (index 1)

index  :  0  1  2  3  4  5
rank   :  1  1  2  3  4  5
          ↑ changed (index 0)

  0     2     3
  ↑
  1     4     5

(1, 2): Find(1) = 0 and Find(2) = 2, so 2’s parent becomes 0. rank[0] becomes 2.

index  :  0  1  2  3  4  5
parent :  0  0  0  3  4  5

index  :  0  1  2  3  4  5
rank   :  2  1  2  3  4  5

  0 ←── 2     3
  ↑
  1     4     5

(2, 3): Find(2) = 0 and Find(3) = 3, so 3’s parent becomes 0.

index  :  0  1  2  3  4  5
parent :  0  0  0  0  4  5

index  :  0  1  2  3  4  5
rank   :  2  1  2  3  4  5

  0 ←── 2
  ↑ ↖
  1   3      4     5

(0, 2): Both have the same parent (0), so a cycle is detected.
