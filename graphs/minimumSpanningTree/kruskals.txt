Kruskal’s Algorithm: Notes

Everything below is in code blocks, so you can copy and paste it as is.

Definition

A greedy algorithm that finds the Minimum Spanning Tree (MST) of a connected, weighted, undirected graph.

Steps
Sort all edges by weight (ascending).
Create a Union-Find (DSU) for all n nodes.
Take each edge in order:
Endpoints in different sets → add the edge and union them ✅
Endpoints in the same set → it forms a cycle, so skip ❌
Stop when the MST has n-1 edges.
Pseudo-code
-----------
sort(edges by weight)
for (u, v, w) in edges:
    if find(u) != find(v):
        union(u, v)
        mstCost += w
        count++
        if count == n-1: break

Graph
 (4)──9──(3)────5────(2)
   \      │ \         │ \
    \     │  \3       │3  \8
     4    1    \      │    (5)
      \   │     \     │   /
       \  │      \    │  /7
        (0)───2───(1)──
Sorted Edges
Edge      Weight   Result
------------------------------
0 → 3        1      ✅ add
0 → 1        2      ✅ add
1 → 3        3      ❌ cycle (skip)
1 → 2        3      ✅ add
0 → 4        4      ✅ add
3 → 2        5      ❌ cycle (skip)
1 → 5        7      ✅ add   (5 edges = n-1, STOP)
Resulting MST
          (0)
        /  |  \
     1 /  2|   \ 4
     (3)  (1)  (4)
          / \
       3 /   \ 7
       (2)   (5)

MST Cost = 1 + 2 + 3 + 4 + 7 = 17

Quick Recap
Sort edges → pick smallest → find(u) != find(v)? → union & add
                                   │
                                   └─ same root? → skip (cycle)

Stop at n-1 edges.
Time: O(E log E)   Space: O(V)
